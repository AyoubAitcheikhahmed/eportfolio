## Context

Cooking is not always inspiring. What'sCooking combines AI with prompt engineering in a browser extension that analyses the contents of your shopping cart and your dietary preferences to suggest recipes.

## What I built

Built as a team during my internship: key features, plus hosting on AWS with infrastructure as code (ECR, App Runner, API Gateway, DynamoDB). AI recommendations use Titan and OpenAI models. We also tested the system and made sure data persisted throughout.
