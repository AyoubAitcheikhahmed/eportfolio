## Context

A client needed a Model Context Protocol (MCP) server in a cloud-native setup, with both back-end and front-end work and secure deployments on OpenShift.

## What I built

- An MCP server and matching client, using Quarkus for the back end and React for the front end.
- CI/CD pipelines with GitLab, Jenkins and ArgoCD on OpenShift.
- A permission system per tool, plus guardrails so access to the MCP tools stays controlled and secure.

The result is a fully operational, secure server with an integrated client, deployed through automated pipelines.
